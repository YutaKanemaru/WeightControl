# ウィジェット（ホーム画面・ロック画面）

（2026-11-26 作成）

アプリを開かなくても、ホーム画面やロック画面で **いまの体重・目標まであと何 kg・期限まであと何日・最近の記録** がひと目で分かるようにします。
「見るたびに記録を思い出す」きっかけにもなるので、続けやすさ（習慣化）にもつながります。

## ウィジェットの種類

| 置く場所 | 大きさ（WidgetKit の名前） | 出すもの |
|---|---|---|
| ホーム画面 | 小（`systemSmall`） | 最新の体重（大きく）、目標まで ○ kg、期限まで ○ 日 |
| ホーム画面 | 中（`systemMedium`） | 左：最新の体重・目標まで・期限まで。右：直近 14 日の記録の小さなグラフ（点と線。目標が記録から 2 kg 以内なら点線の横線も）、今日の記録済みの印・連続記録日数 |
| ロック画面 | 長方形（`accessoryRectangular`） | 最新の体重、目標まで ○ kg・期限まで ○ 日 |
| ロック画面 | 丸（`accessoryCircular`） | 目標までの進み具合のメーター（`Gauge`）と、目標まで ○ kg |
| ロック画面 | 時計の上の 1 行（`accessoryInline`） | 「64.2 kg・目標まで 2.2 kg」 |

- **大きな数字は太く、`monospacedDigit()`**（アプリの見た目の方針と同じ）。アイコンは SF Symbols、色はシステムの色とアクセントカラーだけ。
- ダークモード・文字サイズ・ロック画面の単色表示（`widgetRenderingMode`）で崩れないようにする。
- ウィジェットを押すとアプリのホームが開く。

### それぞれの数字の決め方

アプリのホーム画面と **同じ数字** が出るようにします（ウィジェットだけ違う数字だと迷うため）。

| 項目 | 決め方 |
|---|---|
| 最新の体重 | いちばん新しい記録の体重（ホームの大きな数字と同じ） |
| 目標まで | ホームの「目標まで」と同じ値（最新の体重と目標体重の差。`GoalDistanceCalculator`、[WEIGHT_RECORDS.md](WEIGHT_RECORDS.md)）。0.1 kg 以内か通りこしたら「目標に届いています」 |
| 期限まで | 今日から目標の期限までの日数。期限の日が 0 日、過ぎたら「期限を過ぎました」と責めずに出す |
| 最近の記録 | 直近 14 日の体重。同じ日の記録は平均して 1 日 1 点（ホームのグラフと同じ） |
| 今日の記録 | 今日の記録があれば「今日は記録ずみ」、なければ「今日はまだ」（責めない言い方） |
| 進み具合（ロック画面の丸） | 今の体重の目安（直近 3 週間の直線の今日の値）から。ほめる通知の 25/50/75/100% と同じ考え方 |
| 連続記録日数 | ホームと同じ `WeighInStreakCalculator` の値。記録が昨日より前で途切れていれば出さない |

- 目標がない人は「目標まで」「期限まで」を出さず、体重と記録だけにする。
- 記録がまだない人は「体重を記録しましょう」と出す。
- **キープモード中**（Pro）は「目標まで」の代わりに「キープ中 62.5〜65.5 kg」と範囲を出し、期限は出さない。
- 予測の「目標に届く日」は Pro 機能なので、ウィジェットには出さない（今回はウィジェット自体を無料にするため）。

## 無料か Pro か

**ウィジェットは無料** にします。出すのは無料版でも見られる数字（体重・目標まで・期限まで・記録）だけで、毎日アプリを開くきっかけになるためです。
あとで「届く日」をウィジェットに出す場合は、Pro だけにする（[PRO.md](PRO.md)）。

## しくみ（どう動くのか）

### ウィジェットは別のプログラム

ウィジェットはアプリ本体とは別の小さなプログラム（**Widget Extension**＝アプリに同梱する「拡張機能」）として動きます。
iPhone はウィジェットを描くときにだけこの拡張を短時間動かし、決まった時刻の「表示の予定表」（**タイムライン**）を受け取って、その通りに表示を切り替えます。
アプリ本体と拡張は、同じ iPhone の中でも **別々の箱（サンドボックス）** に入っていて、そのままではお互いのデータを読めません。

### App Group で「共有の引き出し」を作る

**App Group**（同じ開発者のアプリと拡張だけが使える共有の保存場所）を使います。名前は `group.com.utahengineering.weightforecast`。

```
アプリ本体                               ウィジェット（拡張）
SwiftData（記録・目標）                        │
   │ 記録や目標が変わるたびに                    │
   ▼ 表示に必要な数字だけをまとめて書く          │
App Group の UserDefaults ── WidgetSnapshot ──▶ 読んで表示するだけ
   │                                              ▲
   └─ WidgetCenter.reloadAllTimelines() ──────────┘「描き直して」と知らせる
```

- アプリは記録・目標・Pro の状態が変わるたび、アプリを開いたとき（日付が変わっていることがあるため）に、ウィジェットに出す数字をまとめた **`WidgetSnapshot`**（スナップショット＝その時点の写し）を作って、App Group の `UserDefaults` に JSON で保存する。そのあと `WidgetCenter` で「描き直して」と知らせる。
- ウィジェットはそれを読んで表示するだけ。体重の計算はしない。
- 日付が変わると「期限まで ○ 日」「今日の記録」が変わるので、タイムラインには「今」と「次の 0 時」の 2 つを入れ、0 時をすぎたら読み直してもらう。

### なぜ SwiftData のデータベースを共有しないのか

SwiftData の保存場所そのものを App Group に移して、ウィジェットからも読む方法もあります。今回は使いません。

- 保存場所を移すと、**今の記録を新しい場所へ引っ越す処理** が必要になり、失敗すると記録が消えるおそれがある。
- ウィジェットは使えるメモリが小さく、予測の計算をウィジェットでもやると、ホームと数字がずれる・重くなるおそれがある。
- スナップショットなら、計算はアプリの 1 か所（`HomeDashboardBuilder`）のままで、ウィジェットは軽い。

Apple Watch（フェーズ 10）で Watch から記録できるようにするときに、改めてデータの共有のしかたを考える。

### プライバシー

- 体重は人に見られたくない数字なので、ウィジェットの数字には `privacySensitive()`（ロック中は伏せ字にしてよい、という印）を付ける。iPhone がロックされているとき、ロック画面のウィジェットでは数字が伏せられる（設定アプリの「Face ID とパスコード」で変えられる）。
- データは端末の中だけ。App Group も同じ iPhone の中の保存場所で、外には送らない。

## ファイルの置き場所

| 場所 | 中身 |
|---|---|
| `WeightControlApp/Logic/Widget/WidgetSnapshotBuilder` | 記録・目標・ホームの計算結果から `WidgetSnapshot` を作る（テスト付き） |
| `Shared/`（アプリと拡張の両方に入るフォルダ） | `WidgetSnapshot`（保存する形）、`WidgetSnapshotStore`（App Group への読み書き）、`WidgetDisplay`（「期限まで ○ 日」「今日の記録」など、表示の日に合わせた計算。テスト付き） |
| `WeightControlApp/Services/WidgetSnapshotPublisher` | スナップショットを保存して、ウィジェットに描き直しを頼む |
| `WeightControlApp/Views/WidgetSnapshotSync` | 記録や目標の変化に気づいて、上を呼ぶ（`RootView` に 1 行で付ける） |
| `WeightForecastWidget/` | ウィジェット本体（拡張のターゲット）。表示する画面とタイムライン |

## Xcode での準備（開発者が Mac でやること）

プロジェクトファイル（`project.xcproj`）にウィジェットのターゲットと App Group の設定は書いてあるので、ふだんは pull してビルドするだけです。
ただし App Group は **Apple の開発者サイトにも登録が必要** で、これは Xcode が自動でやります。もし赤いエラーが出たら：

1. Xcode の左の一覧でいちばん上の青いプロジェクトを選び、**TARGETS** の `WeightControlApp` →「Signing & Capabilities」を開く。
2. 「App Groups」の欄に `group.com.utahengineering.weightforecast` があり、チェックが入っているか確かめる（なければ ＋ で追加してチェック）。
3. `WeightForecastWidgetExtension` のターゲットでも同じことをする。

### 試し方

1. iPhone（実機かシミュレーター）にアプリを入れて、体重を記録する。
2. ホーム画面の何もない所を長押し →左上の「編集」→「ウィジェットを追加」→「体重予報」を選ぶ。
3. 小・中のどちらかを置く。ロック画面はロック画面を長押し →「カスタマイズ」→ ロック画面 → ウィジェットの欄から追加。
4. アプリで体重を記録し直すと、ウィジェットの数字も変わる（数秒かかることがある）。

## あとで考えること

- ウィジェットから直接「記録する」画面を開く（URL でアプリの記録画面を開くしくみ）。
- Pro の人には「目標に届く日」も出す。
- Apple Watch の文字盤のコンプリケーション（フェーズ 10。ロック画面のウィジェットと同じ部品を使い回せる）。
