# Pro の分け方と、1 か月の無料お試し

（2026-11-21 決定）

体重予報は「記録とグラフはずっと無料、先の見通しは Pro」という分け方にします。
Pro は買い切り（課金のしくみはフェーズ 11 で作る）で、最初に **1 か月の無料お試し** ができます。
お試しが終わっても、Pro の項目は画面に残したまま **中身だけをぼかして**「🔒 Pro で見られます」と出します。

## 無料と Pro の分け方

| 画面・項目 | 無料 | Pro |
|---|---|---|
| 体重の記録・履歴・カレンダー・通知・ヘルスケア連携 | ✅ | ✅ |
| グラフ：測った体重の点、直近 3 週間の直線（実線）、目標の横線、期限の縦線 | ✅ | ✅ |
| 達成の見込み：今のペース（1 週間あたり kg）、「期限に間に合うペースです」などの判定、精度の注意 | ✅ | ✅ |
| 摂取カロリーの目安、無理な目標の修正案、目標の期限の提案、BMI の目安、食べ物ヒント | ✅ | ✅ |
| **目標に届く日**（「このペースなら 2027 年 3 月 8 日ごろ」） | 🔒 ぼかす | ✅ |
| **グラフの点線の予測**（直線の先、目標に届くまで） | 🔒 描かない＋「点線の予測は Pro で見られます」 | ✅ |
| **見込みの幅**（カードとグラフの薄い帯） | 🔒 ぼかしたカード | ✅ |
| **チートデーの提案** | 🔒 提案できるときだけ「提案があります」とぼかしたカード | ✅ |
| **リバウンド抑制モード**（目標に届いたあとの維持。別のスレッドで作る） | 🔒 | ✅ |

### なぜこう分けるのか

- **安全にかかわるものは無料**：無理なペースの注意・修正案・カロリーの下限・BMI の注意は、お金を払わなくても必ず出す。
- **点線も Pro**：点線が目標の横線と交わる所を見れば、届く日が分かってしまうため。直線（今のペース）は無料のまま。
- **「目標に届いています」は無料**：予測ではなく、今の事実なので。
- **期限の提案（ゆるやか／ハード）は無料**：目標を立てるための計画で、予測ではないため。

## ぼかし方のルール

- カードの見出しと「Pro」の札は残し、どんな機能かは分かるようにする。
- ぼかすのは **決まった見本の値**（例: `2027/3/8`）。本当の値はぼかさない（目をこらしたり加工したりで読めてしまうため）。
- VoiceOver は見本を読まず、「目標に届く日は Pro で見られます」だけを読む。
- 「Pro で見られます」を押すと、Pro の説明の画面（`ProOfferView`）を開く。
- 責める言い方や、あおる言い方（「今だけ」「損をします」など）はしない。
- 部品：`Views/Pro/ProLockedContent`（ぼかし＋ボタン）、`ProLockedHint`（1 行の案内）、`LockedProCards`（見込みの幅・チートデーのぼかし版）。新しい Pro 機能もこれを使う。

## 1 か月の無料お試し

- **始め方**：ユーザーが「1 か月無料で試す」を押したときに始まる（インストールした日から自動では始めない。Yuta が選択）。
  - 初回設定を終えたホームのいちばん上に「1 か月無料で試せます」のカード（「くわしく見る」「あとで」）。
  - 設定タブの「Pro について」、ぼかしたカードの「Pro で見られます」からも始められる。
- **長さ**：始めた日の 0 時から 1 か月後の 0 時まで（11 月 21 日に始めたら 12 月 20 日まで）。月末に始めたときは次の月の末日まで。
- **残りの知らせ**：残り 3 日以下になると、ホームに「お試しはあと N 日です」のカード。
- **終わったら**：自動で料金はかからない。Pro の項目はぼかして表示。記録やデータは消えない。
- **やり直し**：一度始めたら、もう一度は始められない。
- 判断は `Logic/Pro/ProAccessPolicy`（テスト `ProAccessPolicyTests`）、状態は `ProAccessStatus`（購入済み・お試し中・お試し終了・まだ始めていない・開発用）。

### App Store の決まり（審査ガイドライン 3.1.1）

買い切りのアプリで期間限定のお試しを出すときは、**0 円の非消耗型の購入項目**（例: 「1か月の無料体験」）として始めることになっています。
始める前に、次の 3 つを画面ではっきり伝える必要があり、`ProOfferView` に書いています。

1. お試しの長さ（1 か月）
2. 終わると見られなくなるもの（目標に届く日・点線の予測・見込みの幅・チートデーの提案）
3. 続けて使うのに必要なお金（Pro の買い切り。自動で料金がかかることはない）

App Store の説明文でも、どの機能が Pro かを書く（審査ガイドライン 2.3.2）。

## 今の作りと、課金（フェーズ 11）で変えること

| | 今 | フェーズ 11（StoreKit 2） |
|---|---|---|
| 購入済みか | いつも「まだ」 | Pro（買い切り）の購入の記録から |
| お試しを始めた日 | 「試す」を押した日時を iPhone の中（`UserDefaults`）に保存。アプリを消すと消える | 0 円のお試しの購入日（`Transaction.purchaseDate`）。Apple 側に残るので、入れ直しても期間は続き、やり直せない |
| 購入ボタン・購入を復元 | 「準備中」と表示 | `ProOfferView` に追加 |
| 開発用 | Debug ビルドだけ「Pro を試す」と「お試しの状態を変える」 | そのまま（StoreKit Configuration ファイルでも試す） |

画面は `ProAccess.status()`／`isUnlocked` だけを見ているので、フェーズ 11 では `Services/ProAccess` の中身を差しかえるだけで済みます。

### 気をつけること

- お試しが終わった瞬間に画面を開いたままだと、次に画面が描き直されるまで中身が見えたままになる（アプリを開き直せば直る）。困るようならフェーズ 11 で、終わる時刻に描き直す。
- お試しの終わりを通知で知らせるかは未定（今はホームのカードだけ）。
