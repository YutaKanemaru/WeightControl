# アプリアイコン「にっこり体重計」

体重計のメーターと笑顔を組み合わせた、図形だけのオリジナルアイコンです（ほめるアプリらしさを表しています）。

| ファイル | 用途 |
|---|---|
| `b-light.svg` | 通常（オレンジの背景に白い体重計） |
| `b-dark.svg` | ダークモード（暗い背景にオレンジの体重計） |
| `b-tinted.svg` | 色付き（ティント）。iOS がユーザーの選んだ色で塗るため、白黒で作る |

- アプリに入っている PNG（1024×1024）は `WeightControlApp/Assets.xcassets/AppIcon.appiconset/` にあります。
- 角の丸みは iOS が自動で付けるので、画像は四角のままで OK です。
- 形を直したいときは SVG を編集して PNG を作り直すか、Xcode の Icon Composer に SVG を読み込んで調整します。
